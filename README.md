# Automated Moderation Discord Bot

A lightweight, efficient Discord moderation bot designed to keep server communities clean, safe, and organized.

---

## Project Overview
This project showcases an automated moderation system capable of filtering inappropriate content, enforcing server rules, and managing member warnings in real time. It is built as a modular portfolio showcase to demonstrate practical Discord bot development in Python.

---

## Key Features
* **Automated Chat Filtering:** Detects and flags banned words or inappropriate language automatically.
* **Warning Escalation System:** Tracks member infractions and triggers automatic timeouts or bans upon reaching configurable warning thresholds.
* **SQLite Database Integration:** Persistently logs user warnings, disciplinary actions, and server logs.
* **Slash Commands:** Clean, user-friendly slash commands (`/warn`, `/warnings`, `/clear`, `/timeout`) for server staff.

---

## Built With
* **Python 3.x**
* **discord.py** (Discord API Wrapper)
* **SQLite3** (Lightweight Database)
